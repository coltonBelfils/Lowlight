Systems programming with nothing hidden.

Lowlight gives you C-level control over memory and data layout with no garbage collector, no null, and no lifetime annotations. Every mutation, move, failure, and early exit is marked right where it happens, so code reads the way it runs.

define Lookup result [
	value: int,
	missing: string,
]

bind find = (stock: #[string: int], item: string) Lookup:
	if(stock[item] as n): value(n)
	else: missing(item.copy())

bind restock = (stock: &#[string: int], item: string, n: int): {
	stock[item.copy()] = (stock[item] ?? 0) + n
}

bind main = (): {
	let stock = #["apples": 3]
	restock(&stock, "pears", 5)       // `&` marks the mutation
	let pears = find(stock, "pears"):
		default missing(what): {
			println("no $what")
			func <-
		}
	println("pears: $pears")
}

Why Lowlight

A small set of rules, each visible in the code you read.

⏚

Deterministic memory

Values are freed at the end of the scope that owns them, in reverse order. No collector, no reference counting, no pauses.

&

Visible effects

A call can change your variable only if you write &x, and take it only if you write own x. Nothing happens behind your back.

?

No null

Absence is an optional type ?T, and every name holding one ends in ?. You cannot forget to check.

!

Failures are values

Operations that can fail return a result type; names holding one end in !. Result chains handle each failure by name.

⇠

Expressions everywhere

if, match, loops, and blocks produce values. Early exits are one operator, <-, aimed at exactly the construct you leave.

⚙

Down to the metal

Raw pointers, packed structs, and C functions are one unsafe away. Compiles to LLVM IR or portable C11.

Ownership you can see

Plain values copy. Resources such as strings and lists have one owner, and moving one is spelled own. A read-only parameter borrows; & lends it for changing.

Ownership in the tour →

bind shout = (s: &string): s.push("!")

bind keep = (s: own string) [string]: [s]

bind main = (): {
	let word = "hello" + ""
	shout(&word)              // borrowed mutably, visibly
	let all = keep(own word)  // moved: `word` is gone
	println(all[0])
}

Patterns, not ceremony

Enums carry data; match takes them apart. Variants are named bare, and every match ends with a default arm the compiler checks for completeness.

Pattern matching →

define Shape enum [
	circle: float,
	rect: +[float, float],
	dot,
]

bind area = (s: Shape) float:
	match(s):
		when circle(r): 3.14159 * r * r
		when rect(wh): wh.0 * wh.1
		default dot: 0.0

bind main = (): println(area(Shape.rect(+[3.0, 4.0])))

Loops that build things

A loop with a result type collects its body's values. The unwind next <- skips an item. No accumulator boilerplate.

Collections and loops →

bind main = (): {
	let words = ["apple", "", "kiwi", "fig"]
	let lengths = for(w in words) [int]: {
		if(w.is_empty()): next <-
		w.len()
	}
	println(lengths)
}
