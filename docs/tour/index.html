#A tour of Lowlight

This tour covers the whole language in twelve short lessons. Each lesson is a handful of small programs that you can copy into a file and run with lowlight run. Their output is shown beneath them, and every one of them is tested against the compiler.

You don't need to know any particular language first, but if you have written some C, Rust, Go, Swift, or TypeScript, much will feel familiar. Where Lowlight differs, the tour says why.
