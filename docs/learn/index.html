#Tutorials

Each tutorial builds a complete program from scratch, explaining each step and the language features it uses. They assume you have installed Lowlight and skimmed the tour.

Beginner

A command-line tool

Read a file, count words with a map, sort them, and print a table. Strings, collections, arguments, and exit codes.

 Intermediate

A calculator

Tokenizer, recursive-descent parser, and evaluator. Enums, match, methods, and Result.

 Intermediate

Handling errors

A config file parser with its own result type, precise failure handling, and error context.

 Intermediate

A web service

An HTTP API with std/http, tested in-process and then served.

 Advanced

Calling C

Declare C functions, pass strings and buffers, and wrap unsafe calls safely.

#More ways to learn

  • Lowlight by Example: short annotated programs, one feature each.
  • Guides: in-depth explanations of ownership, failure handling, generics, testing, and more.
  • The examples/ directory of the repository has larger showcase programs: an arena-allocated graph, a lexer and evaluator, HTTP servers, and a TCP echo server.
