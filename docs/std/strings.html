Package strings

import "std/strings"

#Overview

std/strings — Extended string search, padding, splitting, and manipulation helpers.

Builds on the core prelude methods (is_empty, starts_with, ends_with, index_of, contains, trim, to_upper, to_lower, replace, split, chars, bytes, join_strings) from std/core/primitives and std/chars.

#Types

structdefine ByteBuffer structsource

A growable byte buffer with a read cursor, for binary formats and protocols.

write_* methods append to the end; read_* methods consume from the cursor and return none when too few bytes remain. Multi-byte integers are little-endian by default, with _be variants for big-endian (network byte order).

let b = ByteBuffer.new()
b.write_u16(0x1234)
b.write_u32_be(7)
let x = b.read_u16() ?? 0       // 0x1234
let y = b.read_u32_be() ?? 0    // 7

const methodconst string.lines = fn(self) [string]

Splits this string into lines, removing the line terminators (\n or \r\n).

A final line terminator ends the last line rather than starting an empty one, so "a\nb\n".lines() is ["a", "b"], while "a\nb\n\n".lines() keeps the empty line (["a", "b", ""]). An empty string has no lines.
