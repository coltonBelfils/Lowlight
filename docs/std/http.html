Package http

import "std/http"

#Overview

std/http — HTTP/1.1 client, server, router, URL parser, and test utilities.

Provides Url, Request, Response, ResponseWriter, ServeMux, blocking Client (HTTP and dynamic OpenSSL HTTPS), Server, and in-memory testing helpers (ResponseRecorder, test_handler, test_roundtrip).

Parses a full HTTP/HTTPS URL or relative request target into a structured Url.

Accepts scheme://[user[:password]@]host[:port][/path][?query][#fragment] and relative targets such as /path?query. The path is percent-decoded into Url.path (keeping '+'), query parameters are decoded with '+' as a space, and an omitted port takes the scheme's default_port.

#Types

structdefine Client structsource

Configurable HTTP/HTTPS client with default headers, a request timeout, and redirects.

Fields
  • timeout_ms: int

    Socket connect, write, and response-read timeout in milliseconds (default 15000).

  • headers: Headers

    Default headers attached to outgoing requests when not already present on the Request.

  • max_redirects: int

    How many redirects Client.do follows before failing; 0 returns redirects as is.

Methods
bind Client.delete = (self, url: string) Result[Response]

Sends an HTTP DELETE request to url using this client's configuration.

bind Client.do = (self, req: Request) Result[Response]

Executes req over HTTP or HTTPS (https:// or port 443) and returns the parsed Response.

Populates Host, User-Agent, Accept, Connection: close, Content-Length (when the body is non-empty), and any client-level default headers if not already set on req.

Follows 301, 302, 303, 307, and 308 redirects up to Client.max_redirects: 303 (and 301/302 after a POST) continue with a bodiless GET, while 307 and 308 repeat the method and body. Authorization and Cookie headers are not sent to a different host.

#Errors

Returns Result.err if req.url cannot be parsed, the TCP connection fails, TLS initialization or handshake fails for HTTPS requests (which dynamically requires OpenSSL libssl), sending/receiving fails, the server response is malformed, or more than max_redirects redirects occur (code "too_many_redirects").

bind Client.do_with = (self, req: Request, transport: (Client, Request) Result[Response]) Result[Response]

Like Client.do, but sends each request (the original and every redirect) through transport instead of the network. Tests use it to exercise redirect handling.

bind Client.get = (self, url: string) Result[Response]

Sends an HTTP GET request to url using this client's configuration.

bind Client.new = () Client

Creates a Client with a 15000 ms timeout, no default headers, and up to 10 redirects.

bind Client.patch = (self, url: string, content_type: string, body: string) Result[Response]

Sends an HTTP PATCH request with content_type and body to url.

bind Client.post = (self, url: string, content_type: string, body: string) Result[Response]

Sends an HTTP POST request with content_type and body to url.

bind Client.put = (self, url: string, content_type: string, body: string) Result[Response]

Sends an HTTP PUT request with content_type and body to url.

structdefine Headers structsource

An ordered list of HTTP header fields.

Names compare case-insensitively (ASCII only, as RFC 9110 specifies), keep the spelling they were set with, and may repeat: Set-Cookie and other list-valued fields keep every value in order. Use Headers.get for the first value and Headers.values for all of them.

Methods
bind Headers.add = (&self, name: string, value: string)

Appends a field, keeping any existing fields with the same name.

bind Headers.fields = (self) [HeaderField]

Returns a copy of every field, in order.

bind Headers.get = (self, name: string) ?string

Returns the first value of field name, or none if it is absent.

bind Headers.has = (self, name: string) bool

Reports whether field name is present.

bind Headers.is_empty = (self) bool

Reports whether there are no fields.

bind Headers.len = (self) int

Returns the number of fields, counting repeated names separately.

bind Headers.new = () Headers

Creates an empty Headers.

bind Headers.remove = (&self, name: string) int

Removes every field named name and returns how many were removed.

bind Headers.set = (&self, name: string, value: string)

Sets field name to the single value value: the first existing field with that name is updated in place and later ones are removed, or the field is appended if absent.

bind Headers.values = (self, name: string) [string]

Returns every value of field name, in the order they appear.

structdefine ResponseWriter structsource

Incremental builder used by HTTP server handlers to assemble an outgoing Response.

Call ResponseWriter.set_header and ResponseWriter.write_header before ResponseWriter.write when customizing headers or status codes, then convert to a Response via ResponseWriter.finish.

Fields
  • status_code: int

    HTTP status code recorded for the response (defaults to 200).

  • headers: Headers

    Header fields, in order (see Headers).

  • body: string

    Accumulated response body payload.

Methods
bind ResponseWriter.add_header = (&self, key: string, val: string)

Adds a value for response header key, keeping existing values (for example, several Set-Cookie fields).

bind ResponseWriter.finish = (self) Response

Finalizes defaults (content-length and content-type) and returns the built Response.

If content-type is unset and the body is non-empty, it defaults to "text/plain; charset=utf-8". Status codes <= 0 default to 200.

bind ResponseWriter.header = (self, key: string) ?string

Returns the first value of response header key (compared case-insensitively), or none.

bind ResponseWriter.new = () ResponseWriter

Creates a blank ResponseWriter initialized to 200 OK with empty headers and body.

bind ResponseWriter.set_header = (&self, key: string, val: string)

Sets response header key to a single value val, replacing any existing values.

bind ResponseWriter.write = (&self, text: string)

Appends text to the response body, committing status 200 if no status was set yet.

bind ResponseWriter.write_header = (&self, code: int)

Records the HTTP status code if headers have not yet been written.

structdefine ServeMux structsource

HTTP path multiplexer routing incoming Request values to registered handlers.

Exact path patterns take priority over trailing-slash prefix patterns; among multiple matching prefixes, the longest pattern wins. Unmatched paths fall back to 404 Not Found.

Methods
bind ServeMux.copy = (self) ServeMux

Returns a deep copy of this ServeMux and all registered route handlers.

bind ServeMux.handle_func = (&self, pattern: string, handler: (Request, &ResponseWriter))

Registers handler for requests matching pattern.

  • pattern: Route path. A trailing "/" registers a subtree prefix match; any other path requires an exact match against req.path.
  • handler: Callback invoked with the incoming Request and a mutable ResponseWriter. 
bind ServeMux.new = () ServeMux

Creates an empty ServeMux with no registered routes.

bind ServeMux.serve_http = (self, req: Request, res: &ResponseWriter)

Dispatches req to the matching handler or writes a 404 fallback into res.

structdefine Server structsource

Synchronous HTTP/1.1 TCP server binding to an address and dispatching requests.

Owns the underlying listener socket descriptor and closes it automatically via Server.drop when dropped.

Fields
  • addr: string

    Bind specification such as "127.0.0.1:8080", "8080", or "0.0.0.0:0".

  • port: int

    Actual bound TCP port populated after Server.listen succeeds.

  • listener_fd: int

    Underlying OS listener file descriptor (-1 when closed or unbound).

  • read_timeout_ms: int

    Per-connection request read timeout in milliseconds (default 10000).

  • write_timeout_ms: int

    Per-connection response write timeout in milliseconds (default 10000).

Methods
bind Server.close = (&self)

Closes the listener socket if currently open and resets listener_fd to -1.

bind Server.drop = (&self)

Closes the underlying listener socket when the Server goes out of scope.

bind Server.listen = (&self) Result[int]

Binds the TCP listener socket according to self.addr and returns the bound port.

Supports "host:port", "port", or "host" strings, defaulting omitted host to "0.0.0.0" and omitted port to 8080. Passing port 0 selects an ephemeral OS port stored in self.port.

#Errors

Returns Result.err if binding or listening on the address fails.

bind Server.new = (addr: string) Server

Creates a Server configured to listen on addr with 10000 ms read/write timeouts.

bind Server.serve = (&self, handler: (Request, &ResponseWriter), max_requests: int) Result[int]

Runs the accept loop, handling connections sequentially with handler.

Stops once max_requests valid requests have been served, or runs indefinitely when max_requests <= 0. Returns the total number of valid requests served.

A failed accept (for example, when the process is out of file descriptors) is retried after a delay that starts at 5 ms and doubles up to 1 s, instead of spinning; the delay resets after the next successful accept.

#Errors

Returns an error if listening fails, or a "closed" error if the listener is closed.

bind Server.serve_conn = (&self, conn_fd: int, handler: (Request, &ResponseWriter)) bool

Serves the HTTP requests on connection conn_fd, then closes it.

Requests the client has already pipelined on the connection are answered in order; the connection closes once no further request is waiting, or when the client asks for it with Connection: close. Responses to HEAD carry headers only. A malformed request gets a 400 Bad Request. The handler sees the client's address in Request.remote_addr.

Returns true if at least one request was handled.

bind Server.serve_one = (&self, handler: (Request, &ResponseWriter), timeout_ms: int) Result[bool]

Accepts and serves a single connection, waiting up to timeout_ms milliseconds.

Calls Server.listen automatically if the server is not already listening.

#Errors

Returns a coded "timeout" Error when timeout_ms expires before a client connects, or an error if listening or accepting fails.

structdefine Url structsource

Parsed HTTP or HTTPS Url components including percent-decoded query parameters.

Fields
  • raw: string

    Original unparsed URL string.

  • scheme: string

    URL scheme such as "http" or "https", or empty for relative paths.

  • host: string

    Host and optional port as written ("example.com:8080", "[::1]:8080"), without user information.

  • hostname: string

    Hostname without port or brackets ("example.com", "::1").

  • port: int

    Port number, or the scheme's default port (see default_port) when omitted.

  • path: string

    Percent-decoded path starting with "/". A '+' in a path is a literal plus sign.

  • raw_query: string

    Raw query string without leading "?".

  • query: #[string: string]

    Percent-decoded query parameter key-value map ('+' decodes to a space).

  • raw_path: string

    Path exactly as written, still percent-encoded ("/a%20b"); empty for synthesized URLs.

  • fragment: string

    Fragment after "#", as written; never sent to servers.

  • username: string

    Percent-decoded user name from user:password@host, or empty.

  • password?: ?string

    Percent-decoded password from user:password@host, or none when absent.

Methods
bind Url.query_param = (self, key: string) ?string

Returns the parsed query parameter value for key, or none if absent.

bind Url.to_string = (self) string

Reconstructs a normalized URL or relative path string from this Url.

The port is omitted when it is the scheme's default, so http://x:443/ keeps its port while https://x:443/ does not. User information, the query, and the fragment are kept.
