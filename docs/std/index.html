#Standard library

The standard library is a set of ordinary Lowlight packages under std/. Import one by path and use its exported names through the last path segment:

import "std/fs"

bind main = fn(): {
	let text = fs.read_text("notes.txt") ?? ""
	println(text.len())
}

std/core is the prelude: it is imported into every file automatically, unqualified, and defines the collection types, Result and Error, the methods on primitive types, and the interfaces behind operators and loops. See the prelude chapter of the specification for how the language relies on it.

Every page below is generated from the doc comments in the source, so it is always current. Each declaration links to its source.
