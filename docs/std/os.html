#Functions

const fnconst arch = fn() stringsource

Returns the target CPU architecture identifier string ("arm64", "x86_64", "wasm32", etc.).

funcbind errno_name = fn(code: int) stringsource

The symbolic name of OS error code code (an errno value), such as "ENOENT" or "ECONNREFUSED". Names are the same on every platform even where the numbers differ, so compare names, not numbers. A code the runtime doesn't list is "E<code>".

funcbind error_from_errno = fn(code: int, what: string) Errorsource

An Error for OS error code (an errno value): the message is what followed by the OS's description, and the error's code is the errno name, so e.has_code("EACCES") works.

let e = os.error_from_errno(2, "failed to open \"config.toml\"")
// failed to open "config.toml": No such file or directory
funcbind exec = fn(cmd: string) Result[ExecResult]source

Runs shell command cmd through /bin/sh (popen), capturing its standard output.

A command that runs and fails is still a value: check ExecResult.ok or exit_code (the shell reports a command it can't find as exit code 127).

#Errors

Fails if the shell can't be started at all (for example, no processes or file descriptors are left), with the OS's description.

funcbind mkdir = fn(path: string) MkdirResultsource

Creates a single directory at path (mode 0755). Its parent must already exist; see mkdir_p to create the parents too.

#Errors

MkdirResult.exists if anything already exists at path; MkdirResult.err for any other failure, with the OS's description.

funcbind mkdir_p = fn(path: string) Statussource

Creates the directory path and any missing parents. A directory that already exists is success.

#Errors

Fails if path is empty, if path or one of its parents exists but isn't a directory, or if a directory can't be created, with the OS's description.

funcbind system_run = fn(cmd: string) Result[int]source

Runs cmd through the host shell (system) and returns its exit code, or -1 if it was killed by a signal. Use system_run_status to see the signal.

#Errors

Fails if the shell can't be started, with the OS's description.

funcbind system_run_status = fn(cmd: string) Result[ExecResult]source

Runs cmd through the host shell (system) and returns its full status, including the terminating signal, as an ExecResult with empty stdout.

#Errors

#Types

structdefine ExecResult structsource

Captured output and exit status returned by exec and system_run_status.

Fields
  • stdout: string

    Captured standard output produced by the command (empty for system_run_status).

  • exit_code: int

    Exit code (0 to 255), or -1 if the command was killed by a signal.

  • signal: int

    The signal that terminated the command (9 for SIGKILL), or 0 if it exited normally.

Methods
bind ExecResult.ok = fn(self) bool

Reports whether the command exited cleanly with status 0.

bind ExecResult.signaled = fn(self) bool

Reports whether the command was terminated by a signal rather than exiting.

enumdefine MkdirResult resultsource

The result of mkdir.

Variants
  • value

    The directory was created.

  • exists: Error

    Something (a directory or a file) already exists at the path.

  • err: Error

    Any other failure, with the OS's description (a missing parent, permission denied, ...).
