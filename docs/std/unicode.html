Packages/Standard library

Package unicode

import "std/unicode"

#Overview

std/unicode — Unicode-aware case conversion and case-insensitive comparison.

The prelude's string.to_upper and string.to_lower change only ASCII letters, which is fast and exactly right for protocols, identifiers, and file formats. This package implements the full Unicode default case operations for human-language text:

  • to_upper and to_lower apply the complete mappings, including those that change length ("ß" uppercases to "SS", "ﬁ" to "FI", "İ" lowercases to "i̇") and the Final_Sigma rule ("ΟΔΟΣ" lowercases to "οδος", with a final ς).
  • fold applies full case folding, the form to compare text case-insensitively, and equal_fold compares with it.

The mappings are language-independent: there are no Turkish/Azeri dotted-i or Lithuanian rules. Tables follow the Unicode version in UNICODE_VERSION and are generated by std/unicode/gen_tables.py.

import "std/unicode"

let shout = unicode.to_upper("straße")              // "STRASSE"
let same = unicode.equal_fold("Straße", "STRASSE")   // true

std/unicode tables — GENERATED by std/unicode/gen_tables.py; DO NOT EDIT. Unicode 16.0.0.

#Functions

funcbind equal_fold = (a: string, b: string) boolsource

Reports whether a and b are equal ignoring case, by comparing their full case foldings.

funcbind fold = (text: string) stringsource

Returns the full case folding of text: a caseless form for comparing text case-insensitively ("Straße", "STRASSE", and "strasse" all fold to "strasse"). Folded text is meant for comparison and lookup, not for display.

funcbind to_lower = (text: string) stringsource

Returns text with every character converted to lowercase.

Uses full mappings and applies the Final_Sigma rule: a capital sigma Σ at the end of a word lowercases to ς, and elsewhere to σ.

funcbind to_upper = (text: string) stringsource

Returns text with every character converted to uppercase.

Uses full mappings, so the result may be longer than text ("ß" becomes "SS").
