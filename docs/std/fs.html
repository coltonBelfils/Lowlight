Package fs

import "std/fs"

#Overview

std/fs — RAII file stream I/O (File) and whole-file filesystem helpers.

Provides File with automatic Drop descriptor cleanup along with convenience wrappers (read_file, write_file, read_bytes, copy_file).

Every failure carries the OS's description of what went wrong, and its errno name as the error's code (e.has_code("EACCES")). Failures callers commonly handle on their own, such as a missing file, are separate members of the result.

#Types

structdefine File structsource

Buffered OS file stream supporting binary/text reads, writes, and seeking.

Implements Drop to automatically close the file descriptor at scope exit.

#Example

let f = File.open_write("/tmp/hello.txt"): default panic
f.write_string("hello"): default panic

bind File.read_all_bytes = fn(&self) Result[[u8]]

Reads all remaining bytes from the current stream cursor to EOF into a byte list ([u8]).

Reads in fixed-size chunks without querying the file size, so it works on non-seekable streams such as pipes, FIFOs, and character devices.

#Errors

Fails if the stream is closed or a read fails, with the OS's description.

bind File.read_bytes = fn(&self, max_bytes: int) ReadResult[[u8]]

Reads the next piece of the file: at least one byte and at most max_bytes (which must be positive). Call it until it reports ReadResult.eof.

for(true): {
	let chunk = f.read_bytes(4096):
		when eof(_): for <-
		default err(own e): func <- err(e)
	consume(chunk)
}

#Errors

ReadResult.eof once the whole file has been read; ReadResult.err if the stream is closed, max_bytes isn't positive, or the read fails, with the OS's description.

bind File.read_to_string = fn(&self) Result[string]

Reads all remaining bytes from the current stream cursor to EOF as a [string].

Works on non-seekable streams (pipes, FIFOs, character devices).

#Errors

Fails if the stream is closed or a read fails, with the OS's description.

bind File.seek = fn(&self, offset: int, whence: i32) Result[int]

Moves the file cursor to offset relative to whence (SEEK_SET, SEEK_CUR, or SEEK_END) and returns the new byte offset from the start of the file.

#Errors

Fails if the stream is closed or the seek fails (for example, on a pipe), with the OS's description.

bind File.size = fn(&self) Result[int]

enumdefine FileResult[T] resultsource

The result of opening a file by path (File.open) and of the functions built on it (read_file, read_bytes, file_size, copy_file).

let text = fs.read_file("settings.toml"):
	when not_found(_): ""
	default err(own e): func <- err(e)
Variants
  • value: T

    The opened file, or what was read from it.

  • not_found: Error

    Nothing exists at the path (or a directory on the way to it doesn't).

  • err: Error

    Any other failure, with the OS's description (permission denied, a directory, ...).

enumdefine ReadResult[T] resultsource

The result of File.read_bytes, which reads a file a piece at a time.

Variants
  • value: T

    The bytes read: at least one, and at most the number asked for.

  • eof: Error

    The end of the file was already reached; nothing was read.

  • err: Error

    A read error, with the OS's description.

enumdefine RemoveResult resultsource

The result of remove_file.

Variants
  • value

    The file was removed.

  • not_found: Error

    Nothing exists at the path (or a directory on the way to it doesn't).

  • err: Error

    Any other failure, with the OS's description (permission denied, a directory, ...).

enumdefine RenameResult resultsource

The result of rename_file.

Variants
  • value

    The file was renamed.

  • not_found: Error

    Nothing exists at the old path.

  • err: Error

    Any other failure, with the OS's description (permission denied, a missing destination directory, a move across filesystems, ...).
