Package test

import "std/test"

#Overview

std/test — Test assertion functions and structured diff helpers (@test_only).

Provides aligned single-line and multi-line visual diffs via format_diff along with typed assertions (assert_eq, assert_approx_eq, assert_ne, assert_gt, assert_contains, assert_starts_with, assert_ends_with, assert_is_ok, assert_ok_eq, assert_ok_gt, assert_ok_contains, assert_some, assert_none, and _msg variants).
