NOTE (Audit Comment):

  1. In string.to_json below, the return type is Result[Json, string], so:
    • Line 118-119 (when 't' / when 'f') and line 123 need Result.ok(...) (e.g. func <- Result.ok(Json.bool(true)) and Result.ok(out)).
  2. In to_json_helper, str is an own string parameter (immutable by default unless copied to a let binding), and on line 137 str[1..str.len()-2] drops the last 2 characters instead of 1 (str[1..str.len()-1] strips only the closing quote).
