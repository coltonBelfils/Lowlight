Package strconv

import "std/strconv"

#Overview

std/strconv — Parsing and formatting conversions between strings and primitive scalar types.

Provides optional-safe parsing (to_int, to_float, to_bool, parse_bool) and configurable radix formatting (to_hex, to_bin, to_oct, to_radix) in pure Lowlight.

#Methods on other types

This package adds these methods to types declared elsewhere.

int

bind int.to_radix = (self, radix: int) string

Formats this [int] as lowercase digits in base radix (2..=36), returning "" if invalid.

bind int.to_radix_upper = (self, radix: int) string

Formats this [int] as uppercase digits in base radix (2..=36), returning "" if invalid.

bind int.to_hex = (self, upper: bool) string

Formats this [int] in hexadecimal (uppercase when upper is true).

bind int.to_bin = (self) string

Formats this [int] in base-2 binary without a "0b" prefix.

bind int.to_oct = (self) string

Formats this [int] in base-8 octal without a "0o" prefix.

string

bind string.to_int = (self) ?int

Parses this string as a base-10 signed integer, returning none if invalid or out of range.

bind string.to_int_radix = (self, radix: int) ?int

bind string.to_float = (self) ?float
