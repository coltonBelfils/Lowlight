Package time

import "std/time"

#Overview

std/time — Monotonic clocks, durations, civil calendar DateTime, and formatting/parsing.

Provides Duration, Instant, sleep_ms, and UTC/local DateTime supporting both C/POSIX strftime (%Y-%m-%d) and Go reference layout formats (2006-01-02).

#Types

structdefine DateTime structsource

Civil date-time calendar value with nanosecond precision and timezone offset metadata.

Supports C strftime formats via DateTime.format, Go reference layouts via DateTime.format_go, and duration arithmetic via DateTime.add_duration / DateTime.sub_duration.

#Example

let dt = DateTime.must_new(2026, 1, 15, 9, 30, 0, false)
assert(dt.to_date_only() == "2026-01-15")
Fields
  • year: int

    Full calendar year (e.g. 2026).

  • month: int

    Month of year (1..=12).

  • day: int

    Day of month (1..=31).

  • hour: int

    Hour of day (0..=23).

  • minute: int

    Minute of hour (0..=59).

  • second: int

    Second of minute (0..=59).

  • nanosecond: int

    Fractional nanoseconds within the second (0..=999_999_999).

  • weekday: int

    Day of week (0 = Sunday .. 6 = Saturday).

  • yday: int

    One-based ordinal day of the year (1..=366).

  • offset_secs: int

    Offset east of UTC in seconds.

  • zone_name: string

    Short timezone label such as "UTC" or "LOCAL".

  • unix_secs: int

    Seconds since the Unix epoch (1970-01-01T00:00:00Z).

  • is_local: bool

    Whether this timestamp uses the host local timezone offset.

const methodconst DateTime.format_go = fn(self, layout: string) string

Formats this DateTime using Go reference-time layout tokens ("2006-01-02 15:04:05Z07:00").

Fractional seconds use Go semantics: .000/,000 print exactly that many digits, while .999/,999 drop trailing zeros and omit the fraction (and separator) when it is zero.

#Methods on other types

This package adds these methods to types declared elsewhere.

string

const methodconst string.to_datetime = fn(self) ?DateTime

Parses an ISO 8601 / RFC 3339 date or date-time string into a DateTime, or returns none.

Accepts YYYY-MM-DD, optionally followed by T, t, or a space and HH:MM or HH:MM:SS, an optional fraction (. or , plus 1+ digits; digits past nanoseconds are truncated), and an optional zone designator: Z/z, ±HH:MM, ±HHMM, or ±HH. Times without a zone are UTC. Times with a non-zero offset keep that fixed offset (offset_secs, zone label "+0530"). Out-of-range components (e.g. month 13, 25:00, offset +24:00) are rejected.
