Package chars

import "std/chars"

#Overview

std/chars — ASCII/Unicode scalar [char] classification, case folding, and radix conversion.

Core classification helpers (char.is_digit, char.is_alpha, char.is_alnum, char.is_whitespace, and char.to_int) live in the std/core/primitives prelude.

const methodconst char.is_control = fn(self) bool

Reports whether this character is an ASCII control codepoint (0..=31 or 127 DEL).

const methodconst char.is_punctuation = fn(self) bool

Reports whether this character is an ASCII punctuation mark or symbol.

const methodconst char.to_digit = fn(self, radix: int) ?int

Converts this character to an integer digit (0..radix) in base radix (2..=36), or returns none.

Accepts '0'..'9', 'a'..'z', and 'A'..'Z'. Returns none if radix is out of 2..=36 or the character does not represent a digit smaller than radix.

const methodconst char.len_utf8 = fn(self) int

Returns the UTF-8 encoded byte length (1..=4) of this codepoint, or 0 for surrogates/out-of-range values.
