Packages/Standard library

Package core

import "std/core"

#Overview

std/core — Standard core prelude automatically imported into every Lowlight module.

Aggregates foundational primitives (std/core/primitives), language contract interfaces (std/core/interfaces), error handling (std/core/error, std/core/result), collections (std/core/list, std/core/array, std/core/set, std/core/map), intervals (std/core/range), and hashing (std/core/hash).

std/core/array — Fixed-size stack-allocated contiguous sequence ([N: T]) support.

Provides indexing, containment checks, formatting, and value iteration via Array and ArrayIterator.

std/core/error — Structured error chains and call-site stack traces.

Provides Error and ErrorFrame for composing causal error chains with optional machine-readable error codes and @track_caller source locations.

std/core/hash — Built-in Hashable implementations for Lowlight primitive types.

Scalar primitives use SplitMix64 mixing, normalized floating-point values map -0.0 and +0.0 identically, and [string] uses 64-bit FNV-1a over UTF-8 bytes.

std/core/interfaces — Core language contract interfaces and shared data types.

Defines the foundational interfaces wired to compiler hooks via @lang(...), including Printable, Copyable, Drop, Hashable, Equatable, Comparable, Iterator, Iterable, Collectable, and indexing/containment contracts.

std/core/list — Growable heap-allocated contiguous sequence (List).

Provides amortized O(1) push/pop, bounds-checked lookup, deep copy, deterministic Drop cleanup, and forward Iterator traversal.

std/core/map — Open-addressed hash map (Map) backed by linear probing.

Requires key types implementing Hashable (and Equatable / Copyable for lookup and iteration). Backed by #[K: V] type and literal syntax.

std/core/primitives — Core conversions, comparisons, string utilities, and parsers.

Provides Printable, Equatable, and Comparable implementations on scalar primitives and [string], low-level C-string/raw-buffer helpers, numeric parsers (parse_int, parse_float), and comparison helpers (min, max, abs, clamp).

std/core/range — Half-open (start..end) and closed (start..=end) interval types.

Backs range literals (0..10, 'a'..='z'), loop iteration (for(i in 0..10)), and containment tests (when in 0..=255).

std/core/result — Recoverable error handling via the Result tagged union.

Used throughout the standard library for operations that can fail with a rich Error stack trace instead of panicking.

std/core/set — Open-addressed hash set (Set) backed by linear probing.

Requires element types implementing Hashable (and Equatable / Copyable for containment and iteration). Backed by #[T] type and literal syntax.

funcbind parse_float = (s: string) ?floatsource

Parses a decimal floating-point number (including inf, infinity, nan, signed zero, and arbitrary scientific exponents) from s, or returns none.

The result is correctly rounded. Returns none for invalid syntax, for surrounding whitespace (trim first to accept it), and for finite numbers too large for a [float] ("1e400"); write "inf" for infinity. Numbers too small to represent round to a signed zero.

funcbind parse_int = (s: string) ?intsource

Parses a signed 64-bit integer from s, automatically recognizing 0x (hex), 0b (binary), 0o (octal), or decimal.

Returns none for invalid syntax, values outside the int range, and surrounding whitespace (trim first to accept it).

funcbind parse_int_radix = (s: string, radix: int) ?intsource

Parses a signed 64-bit integer from s in base radix (2..=36), or returns none if invalid or out of range.

Accepts an optional +/- sign and a base prefix (0x, 0b, 0o) matching radix. The whole string must be the number: surrounding whitespace is rejected, so call s.trim() first to accept it.

enumdefine Result[T] resultsource

Represents either a successful value (Result.value) or a failure (Result.err).

Result is an ordinary result declaration: names holding it end in !, and failures are handled with result chains (load(path): default err(own e): func <- err(e.wrap("loading"))), ??, and if(r! as v). Annotated @must_use so callers cannot silently discard failures.

#Example
