Package sort

import "std/sort"

#Overview

std/sort — Depth-bounded Introsort, bottom-up Merge Sort (stable), custom comparator sorting, binary search, lower/upper bounds, and collection ordering helpers.

Extends List ([T]), Array ([N: T]), Set, and Map with sorting and searching operations plus the Sortable contract.
