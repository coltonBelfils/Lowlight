#Get started

Lowlight is a compiled systems language. Programs compile to native executables through LLVM or a portable C11 backend, start instantly, and manage memory deterministically, with no garbage collector.

This section gets you from nothing to a working setup in a few minutes.

Step 1

Install

Build the compiler from source and put it on your PATH.
