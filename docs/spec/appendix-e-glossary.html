#Appendix E: Glossary

TermMeaning
arenaan owner of many values destroyed together, handing out ref[T] references (§7.6)
associated functiona function attached to a type without a receiver, called as Type.name() (§4.4)
binddeclare an immutable name (§4.2)
bodythe block or single expression after a : in a function, if, loop, or arm (§6.1)
borrowtemporary access to a value without owning it; read-only by default, mutable with & (§7.3)
boundan interface a type parameter must satisfy, T: Hashable (§8.2)
comptimecompile-time evaluation context (comptime expr, comptime if/for/match) and comp.* introspection (§4.2)
constdeclare a compile-time constant or compile-time-capable function (§4.2)
destructionreleasing a resource at the end of its owner's scope, running drop first if defined (§7.5)
distinct typea new nominal type with the representation of an existing one (§3.10)
exhaustivecovering every possible value of a match subject (§6.5)
failureany member of a result type other than value (§3.9)
instantiationa copy of a generic declaration with concrete type arguments (§8.4)
labela name on a block or loop, targeted by name <- (§6.7)
movetransfer of a resource to a new owner, leaving the source unusable (§7.2)
narrowingtreating an optional variable as its value inside if(x?) (§6.2)
optional?T, a value that may be absent (§3.5)
ownerthe variable, field, element, temporary, or arena responsible for destroying a value (§7.1)
packageall .ll files in one directory (§4.6)
placean expression that denotes storage: a variable, field, element, or dereference (§5.12)
plain valuea value with no owned resources, copied freely (§3.1)
preludestd/core, imported implicitly into every file (§12)
receiverthe self parameter of a method, in mode self, &self, or own self (§4.4)
resourcea value that owns memory or another resource and therefore moves instead of copying (§3.1)
result chainexpr: when ... default ..., handling a result's failures and evaluating to its value (§6.6)
result typea type declared with result, with one value member and one or more failures (§3.9)
subjectthe value or values a match examines (§6.5)
tag enuman enum with no payloads, each variant an integer (§3.8)
tagged unionan enum with at least one payload variant (§3.8)
trapa panic raised by the language on an invalid operation (Appendix D)
unwind<-, leaving a function, loop, block, or iteration early (§6.7)
vtablethe table of method pointers behind an interface value (§18.7)
