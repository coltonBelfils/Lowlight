#13. The Standard Library

The standard library is a set of ordinary packages under std/. Import each by path; its exported names are used through the last path segment (import "std/fs" gives fs.read_file). This chapter summarizes each package. Run lowlight doc for the complete API with documentation.

PackageContents
std/corethe prelude (§12), imported automatically
std/charscharacter classification (is_ascii, is_ascii_upper, is_control, is_punctuation, ...), case conversion (to_ascii_upper), digits (to_digit(radix), from_digit), len_utf8
std/stringslast_index_of, count, capitalize, repeat, reverse, padding (pad_left_char, center_char), split_whitespace, lines, join, chars_list, bytes_list, is_whitespace, is_ascii; ByteBuffer for reading and writing little- and big-endian integers
std/strconvparsing (string.to_int, to_int_radix, to_float, to_bool, is_numeric, ...) and formatting (int.to_radix, to_hex, to_bin, to_oct, float_to_exp)
std/strfmtnumber formatting (format_int_commas, format_float, format_bytes, format_percent, format_currency), padding (pad_left, center, pad_int_zeros), case styles (to_title, to_snake_case, to_kebab_case, to_camel_case), quote, unquote, indent, truncate
std/mathsqrt, cbrt, pow, exp, log, log2, log10, trigonometric and hyperbolic functions, floor, ceil, round, trunc, fmod, hypot, is_nan, is_inf, clamp_int, clamp_float, lerp, angle conversions, PI and related constants
std/sortsort, sort_by, stable_sort, is_sorted, binary_search, lower_bound, upper_bound, reverse for lists and arrays (as methods and functions); Set.to_sorted_list, Map.to_sorted_keys
std/fsthe File resource (File.open, open_read, open_write, open_append, read_to_string, read_bytes, write_string, write_bytes, seek, tell, size, flush, close; closes itself on drop) and functions read_file, write_file, append_file, read_bytes, write_bytes, exists, file_size, remove_file, rename_file, copy_file. Opening and reading by path return FileResult[T] (separating not_found); File.read_bytes returns ReadResult[T] (separating eof); writes, flush, and close return Status; remove_file and rename_file return RemoveResult and RenameResult (separating not_found). Every failure carries the OS's description, with the errno name as its code
std/osexec, system_run, and system_run_status (a Result of an ExecResult with stdout, exit_code, and the terminating signal; a failure only when the shell can't start), mkdir (a MkdirResult separating exists), mkdir_p and remove_all (Status), errno_name and error_from_errno for OS errors, file_exists, num_cpus, os_name, arch
std/timeDuration, Instant (now, elapsed), DateTime (new, must_new, now_utc, now_local, from_unix_secs, formatting and parsing with layouts such as RFC3339), sleep_ms, calendar helpers
std/netTcpStream (connect, send/recv for strings and send_bytes/recv_bytes for [u8], shutdown, peer_addr, local_addr, set_nodelay, close), TcpListener (listen, accept, port), dial_tcp, listen_tcp, socketpair, format_ipv6. connect separates not_found (an unresolvable host), refused, and timeout; recv separates eof and timeout; accept separates timeout; listen separates in_use
std/httpURL parsing, Request and Response, a client (get, post, put, ...; a RequestResult separating unreachable and timeout), a server with routing (ServeMux, listen_and_serve; Server.listen separates in_use, serve_one separates timeout), and STATUS_* constants
std/poolPool[T] with generational Handle[T]s: alloc, get, with_mut, set, take, free, iteration
std/collectionsDeque[T] (a ring buffer: push_front, push_back, pop_front, pop_back, front, back, get), Queue[T] (first in, first out: push, pop, peek), BitSet (non-negative ints, one bit each, with union, intersection, difference, is_subset), PriorityQueue[T] (a binary heap ordered by a closure; min_first and max_first for Comparable elements; push, pop, peek, drain), StringInterner (intern, id_of, name_of), and BTreeMap[K: Comparable, V] (an ordered map: insert, get, remove, update, with, first, last, range, entries of Entry[K, V])
std/testassertions for tests: assert_eq, assert_ne, assert_true, assert_false, assert_gt/lt/ge/le, assert_approx_eq, assert_contains, assert_starts_with, assert_ends_with, assert_some, assert_none, result assertions (assert_is_ok, assert_is_err, assert_ok_eq, assert_err_contains, ...), batch forms (assert_all_*, assert_any_eq), and a _msg variant of each
std/unicodefull Unicode case conversion: to_upper, to_lower (with the Final_Sigma rule), fold, equal_fold, UNICODE_VERSION; mappings may change length (ß → SS) and are language-independent. The prelude's string.to_upper/to_lower stay ASCII-only
std/jsonJSON values and conversion (work in progress)

All of these follow the failure conventions of §9.1: operations that can fail because of the outside world return Result, and lookups that may find nothing return ?T.
